# FastAPI Social API

Учебный backend-проект небольшой социальной сети.

Проект сделан для практики FastAPI, PostgreSQL, SQLAlchemy, JWT-аутентификации и тестирования API.

## Возможности

- регистрация пользователей;
- авторизация по email и паролю;
- JWT-токены;
- хеширование паролей;
- поиск пользователей;
- создание постов;
- поиск постов;
- создание комментариев;
- получение комментариев к посту;
- защищённые endpoints для постов и комментариев;
- работа с PostgreSQL;
- миграции базы данных;
- асинхронные тесты API.

## Аутентификация

Для авторизации используется OAuth2 с JWT-токенами.

После успешного входа пользователь получает access token:

```json
{
  "access_token": "..."
}
```

Токен передаётся в заголовке:

```text
Authorization: Bearer <token>
```

Некоторые endpoints доступны только авторизованным пользователям.

Пароли не хранятся в открытом виде. Перед сохранением они хешируются с помощью `bcrypt`.

## Основные модели

### User

Пользователь социальной сети.

Хранит:

- имя;
- email;
- хеш пароля.

Email пользователя должен быть уникальным.

### Post

Пост пользователя.

Хранит:

- автора;
- заголовок;
- описание.

### Comment

Комментарий к посту.

Хранит:

- пользователя;
- пост;
- текст комментария.

## API

### Пользователи

Создание пользователя:

```http
POST /create_user
```

Поиск пользователей по имени:

```http
GET /search/users?name=...
```

### Авторизация

Вход:

```http
POST /login
```

В качестве логина используется email пользователя.

### Посты

Создание поста:

```http
POST /create_post
```

Требуется авторизация.

Поиск постов по заголовку:

```http
GET /search/posts?title=...
```

### Комментарии

Создание комментария:

```http
POST /comments
```

Требуется авторизация.

Получение комментариев поста:

```http
GET /comments?post_id=...
```

## Работа с базой данных

Для работы с PostgreSQL используется асинхронный SQLAlchemy.

Подключение создаётся через `create_async_engine`, а работа с базой выполняется через `AsyncSession`.

В проекте используются:

- ORM-модели;
- связи между таблицами;
- асинхронные запросы;
- `commit` и `rollback`;
- обработка `IntegrityError`;
- миграции Alembic.

## Тестирование

Для тестирования используются `pytest`, `pytest-asyncio` и `httpx`.

Проверяются:

- регистрация пользователя;
- повторная регистрация с уже существующим email;
- требования к длине пароля;
- успешная и неуспешная авторизация;
- доступ к защищённым endpoints;
- создание постов;
- создание комментариев;
- работа JWT-токенов;
- обработка некорректных и просроченных токенов.

## Настройка

Для работы проекта необходим PostgreSQL.

Нужно задать переменные окружения:

```env
DB_USER=...
DB_PASSWORD=...
DB_NAME=...
DB_HOST=...
DB_PORT=...
SECRET=...
```

`SECRET` используется для создания и проверки JWT-токенов.

После настройки базы данных нужно применить миграции:

```bash
alembic upgrade head
```

## Запуск

Запуск FastAPI-приложения:

```bash
uvicorn src.main:app --reload
```

После запуска Swagger будет доступен по адресу:

```text
http://127.0.0.1:8000/docs
```
